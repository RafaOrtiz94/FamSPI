# Guía de uso — Archivos Adjuntos

> **Para quién es esta guía:** Técnicos, comerciales y gerencia que necesitan adjuntar, descargar o eliminar archivos dentro de las solicitudes del sistema.

---

## ¿Para qué sirve este módulo?

Este módulo maneja los archivos adjuntos que van dentro de una solicitud. Cuando creas un trámite, a menudo necesitas acompañarlo con documentos de soporte: cotizaciones, fotos, PDFs, planillas, etc. Este módulo se encarga de guardar, organizar y permitir acceder a esos archivos desde la solicitud correspondiente.

Funciona como complemento del módulo de Solicitudes: no existen los archivos "por sí solos", siempre están vinculados a un ID de solicitud.

---

## ¿Quién puede usarlo?

| Rol o perfil | ¿Qué puede hacer? |
|---|---|
| Técnico | Subir archivos, ver archivos de sus solicitudes |
| Comercial | Subir archivos, ver archivos de sus solicitudes |
| Gerencia | Ver y eliminar archivos de cualquier solicitud |
| Admin | Ver y eliminar archivos de cualquier solicitud |

> Los archivos se agrupan por el ID de la solicitud. Solo puedes ver los archivos de las solicitudes a las que tienes acceso.

---

## Pantalla principal

La gestión de archivos ocurre dentro de cada solicitud. Cuando abres una solicitud, verás una sección de **"Archivos adjuntos"** que lista:

- Nombre del archivo.
- Tamaño.
- Fecha de carga.
- Usuario que lo subió.

### ¿Qué significa cada estado?

| Lo que ves | Qué significa |
|---|---|
| Archivo en la lista | Está disponible para descargar |
| Sin archivos en la lista | Nadie ha subido archivos a esta solicitud todavía |

---

## Flujo principal — Adjuntar archivos a una solicitud

### Paso 1 — Abrir la solicitud

Ve a la solicitud donde necesitas agregar archivos. Esta solicitud debe estar en estado de borrador o edición; no se pueden subir archivos a solicitudes ya cerradas.

### Paso 2 — Tocar "Adjuntar archivos" o "+"

Busca el botón con el signo **"+"** o el texto **"Subir archivos"**.

### Paso 3 — Seleccionar los archivos

Elige uno o varios archivos desde tu equipo:

- Cotizaciones o presupuestos.
- Imágenes del equipamiento o evento.
- PDFs de especificaciones técnicas.
- Planillas de cálculo.
- Cualquier documento relevante para el trámite.

### Paso 4 — Confirmar la subida

Toca **"Subir"** o **"Cargar"**. El sistema guarda los archivos y los asocia al ID de la solicitud.

> **Nota:** Los archivos se almacenan temporalmente en el servidor. Si tienes archivos muy grandes o muchos archivos, asegúrate de esperar a que la subida termine completamente antes de cerrar la página.

---

## Flujo principal — Ver archivos de una solicitud

### Paso 1 — Abrir la solicitud

Abre el trámite correspondiente.

### Paso 2 — Revisar la lista de archivos

En la sección de adjuntos verás todos los documentos cargados.

### Paso 3 — Descargar un archivo

Toca el nombre del archivo o el ícono de **descargar** (flecha hacia abajo). Se abrirá o descargará según la configuración de tu navegador.

---

## Flujo principal — Eliminar un archivo

### Paso 1 — Buscar el archivo

En la lista de adjuntos, identifica el archivo que deseas eliminar.

### Paso 2 — Tocar "Eliminar"

Toca el ícono de **papelera** o **"Eliminar"** junto al archivo.

### Paso 3 — Confirmar

Confirma la eliminación. El archivo se borra del sistema de forma permanente.

> **Atención:** Solo gerencia y admin pueden eliminar archivos de cualquier solicitud. Los técnicos y comerciales solo pueden eliminar archivos de sus propias solicitudes.

---

## Flujo principal — Filtrar documentos por solicitud

### Paso 1 — Ingresar a la solicitud objetivo

El filtrado principal se hace por solicitud. Cada solicitud tiene sus propios archivos listados de forma independiente.

### Paso 2 — Revisar solo los adjuntos relevantes

Al estar agrupados por solicitud, siempre ves exactamente los archivos vinculados a ese trámite, sin mezcla de otros procesos.

## Preguntas frecuentes

**[No puedo subir un archivo]**

Verifica que:
- La solicitud esté en estado editable.
- El archivo no pese demasiado (si hay problemas, contacta a TI).
- El formato sea aceptado por el sistema (PDF, Word, Excel, imágenes).

**[Subí el archivo equivocado]**

Si todavía puedes editar la solicitud, elimina el archivo incorrecto y sube el correcto. Si la solicitud ya está cerrada, contacta al responsable del área para que la reabra o la corrija.

**[El archivo subido no se ve]**

Recarga la página. Si sigue sin aparecer, verifica que la subida haya terminado completamente (a veces hay retrasos por peso del archivo).

**[Gerencia borró un archivo que yo necesitaba]**

Los archivos eliminados no se pueden recuperar. Contacta a la persona que generó la solicitud para que vuelva a subirlo.

|---|---|
| Adjuntar un documento a un trámite | Abre la solicitud → "Subir archivos" |
