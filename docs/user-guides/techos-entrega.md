# Guía de uso — Techos de Entrega

> **Para quién es esta guía:** Comercial, operaciones, logística, servicio técnico y gerencia que planifica y consulta los límites de capacidad de entrega de equipos.

---

## ¿Para qué sirve este módulo?

Este módulo muestra los **topes máximos de entrega** configurados para la empresa. Cada período (semana, mes, trimestre) tiene una capacidad límite de equipos que se pueden entregar a clientes, según la disponibilidad de stock, personal técnico y logística.

Sirve para que las áreas comerciales y operativas no prometan entregas que superen la capacidad real del negocio.

## Pantalla principal

La pantalla principal es **"Techos de entrega"** dentro del área Comercial.

Verás una tabla o calendario que muestra:

- **Período**: semana, mes o rango de fechas.
- **Capacidad máxima**: cantidad de equipos que se pueden entregar en ese período.
- **Comprometido**: cuántas entregas ya están reservadas.
- **Disponible**: espacio restante para nuevas entregas.

---

## Flujo principal — Consultar la capacidad disponible

### Paso 1 — Ingresar a "Techos de entrega"

En el área Comercial, selecciona **"Techos de entrega"** o **"Máximos de entrega"**.

### Paso 2 — Seleccionar el período

Elige el mes o semana que te interesa planificar.

### Paso 3 — Revisar la capacidad

Identifica:

- Cuántas entregas ya están comprometidas.
- Cuántas puedes agregar sin superar el límite.
- Si hay capacidad disponible para una nueva entrega.

---

## Flujo principal — Planificar una entrega usando los techos

### Paso 1 — Consultar disponibilidad actual

Revisa el techo del período en el que planeas entregar.

### Paso 2 — Coordinar con operaciones

Si necesitas agregar una entrega nueva, consulta con Operaciones o Logística para confirmar que haya cupo disponible.

### Paso 3 — Reservar capacidad

Una vez que confirmas la entrega, el sistema descuenta automáticamente ese cupo del techo al crear la solicitud de entrega o la compra correspondiente.

---

## Flujo principal — Comparar períodos

### Paso 1 — Cambiar de mes o semana

Usa el selector de fechas para ver distintos períodos.

### Paso 2 — Identificar cuellos de botella

Si ves que un mes está lleno mientras el siguiente tiene espacio, planifica las entregas futuras para equilibrar la carga.

---

## Preguntas frecuentes

**[El sistema me deja programar más entregas de las que indica el techo]**

El sistema no bloquea la creación de compras o solicitudes por sí solo. Los techos son una referencia para planificar; la validación real de capacidad puede ocurrir en otro punto del flujo (por ejemplo, en la confirmación de fecha de entrega).

**[No veo el techo de un mes futuro]**

Asegúrate de que el mes esté dentro del rango configurado. Si necesitas ver planificación a más largo plazo, contacta a Administración o Gerencia.

**[Los techos cambian sin aviso]**

Los topes se configuran de forma centralizada. Si detectas cambios que no coinciden con la realidad operativa, avisa a Gerencia o Administración.
