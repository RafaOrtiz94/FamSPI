# Guía de uso — Usuarios

> **Para quién es esta guía:** Personal de Talento Humano, gerencia y TI que administra las identidades y roles de los colaboradores dentro del sistema.

---

## ¿Para qué sirve este módulo?

Este módulo es la consola de administración de personas del sistema. Aquí se crean, editan y controlan las cuentas de cada colaborador, incluyendo a qué rol pertenece (comercial, técnico, gerencia, etc.). Cada usuario es la puerta de entrada a los módulos que puede usar: su rol determina qué ve y qué puede hacer en la plataforma.

Además, este módulo expone el catálogo de roles disponibles, que se usa en formularios de toda la aplicación para asignar permisos.

---

## ¿Quién puede usarlo?

| Rol o perfil | ¿Qué puede hacer? |
|---|---|
| Talento Humano / jefe de TH | Ver, crear, editar y eliminar usuarios |
| Gerencia | Ver, crear, editar y eliminar usuarios |
| TI / jefe de TI | Ver, crear, editar y eliminar usuarios |
| Admin / administrador | Acceso completo |
| Finanzas, comercial y otros roles | Solo ver el listado de usuarios |

> Un usuario con rol de lectura puede buscar personas, pero no puede modificar sus datos ni cambiarles el rol.

---

## Pantalla principal

La gestión de usuarios está dentro de la sección **"Usuarios y Departamentos"** del área de **Talento Humano**.

Verás una **tabla** con todos los colaboradores registrados. Cada fila incluye información básica como nombre, correo, rol y estado.

### ¿Qué significa cada estado?

| Lo que ves | Qué significa |
|---|---|
| Activo | El usuario puede ingresar al sistema y usar sus módulos |
| Inactivo | La cuenta está bloqueada; no puede ingresar |

---

## Flujo principal — Crear un usuario nuevo

### Paso 1 — Tocar "Nuevo usuario" o "+"

Busca el botón con signo **"+"** o el texto **"Crear usuario"** en la parte superior de la tabla.

### Paso 2 — Completar los datos

Se abrirá un formulario. Completa al menos:

1. **Nombre completo**: cómo se llama la persona.
2. **Correo electrónico**: debe ser una cuenta válida de la empresa (ejemplo: `nombre.apellido@fam-project.com`).
3. **Rol**: selecciona de la lista el rol que corresponde a su puesto (comercial, técnico, gerencia, etc.).

### Paso 3 — Guardar

Toca **"Guardar"**. El sistema crea la cuenta y el usuario ya podrá ingresar con su Google.

> **Importante:** Si el usuario todavía no aceptó el aviso de privacidad (LOPDP), verá la pantalla **"Registro en proceso"** hasta que lo complete.

---

## Flujo principal — Editar datos de un usuario

### Paso 1 — Seleccionar el usuario

Busca a la persona en la tabla y toca el ícono de **editar** (lápiz).

### Paso 2 — Modificar lo necesario

Puedes cambiar:

- El **rol** (si la persona asciende, cambia de área o se reasigna).
- El **departamento** (cuando se mueve de equipo).
- El **estado** (activo o inactivo).

### Paso 3 — Guardar cambios

Toca **"Guardar"**. Los cambios aplican de inmediato.

---

## Flujo principal — Cambiar el estado de un usuario

### Activar un usuario

Si un usuario está inactivo (por ejemplo, volvió de vacaciones):

1. Busca su registro en la tabla.
2. Toca la opción **"Activar"** (icono de check verde).
3. Confirma. El usuario podrá ingresar de nuevo.

### Desactivar un usuario

Si un usuario se va de la empresa o se ausenta por un tiempo:

1. Busca su registro en la tabla.
2. Toca la opción **"Desactivar"** (icono de círculo con equis).
3. Confirma. El usuario no podrá ingresar al sistema hasta que se reactive.

---

## Flujo principal — Buscar usuarios

En la parte superior de la tabla hay un campo de búsqueda.

Escribe el **nombre** o el **correo** del usuario y la lista se filtra de inmediato. Esto es útil cuando la empresa tiene varios colaboradores y necesitas encontrar a alguien rápido.

---

## Flujo principal — Filtrar por departamento

Si la tabla lo permite, usa el filtro de departamento para ver solo los usuarios de un área específica (por ejemplo, todos los de "Comercial" o todos los de "Servicio Técnico").

---

## Flujo principal — Eliminar un usuario

Solo roles autorizados pueden eliminar usuarios.

### Paso 1 — Seleccionar el usuario

Busca a la persona y toca el ícono de **eliminar** (papelera o equis).

### Paso 2 — Confirmar

El sistema te pedirá confirmación. Ten en cuenta que esta acción **no se puede deshacer**. Si el usuario tiene registros históricos (solicitudes, asistencias, aprobaciones), considera desactivarlo en su lugar para conservar trazabilidad.

### Paso 3 — Eliminar

Toca **"Eliminar"** o **"Confirmar eliminación"**. La cuenta desaparece del sistema.

---

## Preguntas frecuentes

**[Creé un usuario con el correo equivocado]**

Edita el registro y corrige el correo. Si el usuario ya intentó ingresar con el correo incorrecto, igualmente podrá acceder con el nuevo sin problemas.

**[Le cambié el rol pero no ve los módulos correspondientes]**

El cambio de rol aplica en el siguiente inicio de sesión. Pide al usuario que cierre sesión y vuelva a entrar.

**[No tengo la opción de editar]**

Solo pueden editar usuarios las personas con rol de Talento Humano, TI, gerencia o admin. Si crees que deberías tener acceso, solicita a TI que revisen tu rol.

**[Eliminé el usuario de un colaborador que sigue trabajando]**

Si eliminaste la cuenta por error, debes volver a crearla con el mismo correo. El usuario podrá ingresar de nuevo, pero los datos históricos de esa cuenta se pierden. Si solo querías suspender el acceso, usa la opción "Desactivar" en su lugar.

## Resumen rápido

| Si necesitas... | Haz esto |
|---|---|
| Agregar una persona al sistema | Toca "+" y completa nombre, correo y rol |
| Cambiar el rol de alguien | Toca el lápiz junto al usuario y edita el rol |
| Suspender el acceso | Toca "Desactivar" |
| Reactivar a alguien | Toca "Activar" |
| Buscar a alguien | Escribe en el campo de búsqueda |
| Eliminar permanentemente | Toca la papelera (solo si no necesitas conservar historial) |
