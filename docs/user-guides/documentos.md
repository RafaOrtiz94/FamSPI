# Guía de uso — Documentos

> **Para quién es esta guía:** Todo colaborador que necesita subir, consultar, descargar o gestionar documentos asociados a trámites del sistema.

---

## ¿Para qué sirve este módulo?

Este módulo es el repositorio general de documentos del sistema. Aquí se almacenan archivos que acompañan a solicitudes, procesos o gestiones internas que necesitan respaldo documental. A diferencia de los archivos adjuntos a una solicitud específica, este módulo permite gestionar documentos de forma independiente, sin estar atados a un trámite en particular.

Sirve para mantener toda la evidencia documental organizada y accesible desde un solo lugar.

---

## ¿Quién puede usarlo?

El acceso a este módulo depende de la configuración de rutas y el consumo que hagan otros módulos. Generalmente, cualquier usuario autenticado puede ver documentos en los módulos donde aparecen, pero la gestión directa desde este módulo puede estar habilitada para roles específicos (talento humano, backoffice, calidad, etc.).

---

## Pantalla principal

La pantalla principal muestra una **lista de documentos** disponibles. Cada documento incluye:

- **Nombre del archivo**.
- **Tipo de documento** (si el sistema lo clasifica).
- **Fecha de creación o carga**.
- **Propietario o área responsable** (si aplica).

Según el módulo desde el que accedas, verás solo los documentos relacionados a ese área. Por ejemplo, desde "Solicitudes" verás los documentos de trámites específicos; desde aquí verás el repositorio general.

---

## Flujo principal — Consultar documentos

### Paso 1 — Ingresar al módulo

Ve al menú principal y busca la opción **"Documentos"** (acceso directo compartido).

### Paso 2 — Buscar el documento

Usa el campo de búsqueda o los filtros disponibles para encontrar el documento que necesitas:

- Por **nombre** o palabra clave.
- Por **tipo de documento**.
- Por **fecha** de carga.

### Paso 3 — Abrir o descargar

Toca el documento para abrirlo en el navegador o descargarlo a tu equipo.

---

## Flujo principal — Subir un documento

### Paso 1 — Tocar "Nuevo" o "Subir documento"

Busca el botón para agregar un archivo nuevo.

### Paso 2 — Seleccionar el archivo

Elige el documento desde tu equipo (PDF, imagen, Excel, etc.).

### Paso 3 — Completar la información

Si el sistema lo requiere, agrega:

- **Nombre o descripción** del documento.
- **Etiqueta o categoría** (si hay opciones predefinidas).
- **Vincular a un trámite** (opcional).

### Paso 4 — Guardar

Toca **"Guardar"** o **"Subir"**. El documento queda disponible en el repositorio y puede ser visto por las personas autorizadas.

> **Nota:** Algunos documentos se suben desde módulos específicos (por ejemplo, archivos adjuntos a una solicitud). En esos casos, el documento se registra automáticamente en el módulo correspondiente.

---

## Flujo principal — Modificar o reemplazar un documento

### Paso 1 — Seleccionar el documento

Busca el documento en la lista y toca la opción de **editar** (ícono de lápiz) o **reemplazar**.

### Paso 2 — Subir el nuevo archivo

Selecciona el archivo actualizado desde tu equipo.

### Paso 3 — Guardar

Toca **"Guardar"**. El sistema puede conservar la versión anterior como historial o reemplazarla directamente, según la configuración.

---

## Flujo principal — Eliminar un documento

### Paso 1 — Seleccionar el documento

Busca el documento y toca el ícono de **eliminar** (papelera o equis).

### Paso 2 — Confirmar

El sistema te pedirá confirmación. Toca **"Eliminar"** o **"Confirmar"**.

> **Atención:** Algunos documentos son necesarios para procesos en curso (por ejemplo, una solicitud aprobada que necesita sus archivos adjuntos). Si el sistema bloquea la eliminación, significa que el documento está vinculado a un proceso activo. Debes cancelar o cerrar ese proceso antes de poder eliminarlo.

---

## Preguntas frecuentes

**[Subí un documento con el nombre equivocado]**

Si el sistema lo permite, edita el documento para cambiarle el nombre o descripción. Si no puedes editar, contacta a la persona que gestiona el área para que lo corrija.

**[No puedo eliminar un documento]**

Probablemente está vinculado a una solicitud o proceso activo. Cierra o cancela ese proceso primero, o contacta a un administrador.

**[El documento no se sube]**

Verifica que el archivo no supere el tamaño permitido y que esté en un formato aceptado (PDF, Word, Excel, imágenes). Si el problema persiste, avisa a TI.

**[Perdí un documento que estaba en el sistema]**

Usa la búsqueda por nombre o fecha para intentar localizarlo. Si no aparece, consulta al responsable del área donde lo cargaron; puede haber sido eliminado o movido.

---

## Resumen rápido

| Si necesitas... | Haz esto |
|---|---|
| Buscar un documento | Ingresa a "Documentos" y usa el buscador |
| Subir un archivo nuevo | Toca "Nuevo" y selecciona el archivo |
| Corregir un documento | Toca el ícono de editar y sube la versión actualizada |
