# Guía de uso — Solicitudes de Entrega

> **Para quién es esta guía:** Comercial, operaciones, logística y servicio técnico que coordina fechas de entrega de equipos a clientes.

---

## ¿Para qué sirve este módulo?

Este módulo gestiona las **solicitudes de entrega** de equipos. Funciona como un sub-flujo dentro de las compras de equipos (públicas y privadas). Cuando un equipo ya fue comprado, inspeccionado y está listo para enviar al cliente, se crea una solicitud de entrega para coordinar:

- La fecha y hora de entrega.
- El lugar de entrega.
- La persona que recibe el equipo.
- La confirmación de que la entrega se realizó.

Es un módulo pequeño pero clave: asegura que cada equipo llegue a su destino y que quede registro de quién lo recibió y cuándo.

## Pantalla principal

La pantalla muestra una lista de **solicitudes de entrega** con:

- Compra asociada.
- Cliente destinatario.
- Fecha de entrega solicitada.
- Estado de la entrega.

### ¿Qué significa cada estado?

| Estado | Qué significa |
|---|---|
| **Solicitada** | Se pidió una fecha de entrega, esperando confirmación del área operativa |
| **Confirmada** | Operaciones o logística confirmó que la entrega se realizó |
| **Cancelada** | La entrega se canceló |

---

## Flujo principal — Crear una solicitud de entrega (comercial)

### Paso 1 — Ingresar al módulo

La solicitud de entrega generalmente se crea desde el **workspace de compras** correspondiente (equipo público o privado). Busca la opción **"Solicitar fecha de entrega"** o **"Crear solicitud de entrega"**.

### Paso 2 — Completar los datos

- **Compra asociada**: selecciona la orden de compra o compra privada correspondiente.
- **Cliente destinatario**: quién recibe el equipo.
- **Fecha deseada**: cuándo te gustaría que se entregue.
- **Lugar de entrega**: dirección exacta.
- **Observaciones**: instrucciones especiales (horario de atención, persona de contacto, etc.).

### Paso 3 — Enviar

Toca **"Solicitar"**. El sistema notifica a operaciones o logística para gestionar la entrega.

---

## Flujo principal — Confirmar una entrega realizada

### Paso 1 — Ver las solicitudes pendientes

En el área de **Operaciones** o **Logística**, busca las solicitudes de entrega pendientes.

### Paso 2 — Confirmar la entrega

Cuando el equipo ya fue entregado al cliente:

1. Toca la solicitud.
2. Toca **"Confirmar entrega"**.
3. Agrega observaciones si es necesario (ejemplo: "Entregado en recepción, firmó el guardia").

### Resultado

La solicitud pasa a estado **"Confirmada"** y queda registrada en el sistema.

---

## Flujo principal — Consultar historial de entregas

### Paso 1 — Filtrar por estado o fecha

En el listado, usa los filtros para ver:

- Entregas confirmadas de este mes.
- Entregas pendientes.
- Entregas por cliente o compra.

## Preguntas frecuentes

**[El cliente no puede recibir el equipo en la fecha solicitada]**

Coordina una nueva fecha con el cliente y actualiza la solicitud si el sistema lo permite, o cancela y crea una nueva solicitud con la fecha corregida.

**[Confirmé la entrega pero el cliente dice que no la recibió]**

Verifica la fecha y hora registrada en el sistema. Si hubo un error, contacta a operaciones para corregir el registro.

**[No veo algunas solicitudes de entrega]**

Las solicitudes están vinculadas a una compra específica. Asegúrate de filtrar correctamente o buscar desde el workspace de la compra correspondiente.

## Resumen rápido

| Si necesitas... | Haz esto |
|---|---|
| Solicitar la entrega de un equipo comprado | Ve al workspace de la compra → "Solicitar fecha de entrega" |
| Confirmar que un equipo fue entregado | Ve a Operaciones/Logística → toca "Confirmar entrega" |
| Ver entregas pendientes | Filtra la lista por estado "Solicitada" |
