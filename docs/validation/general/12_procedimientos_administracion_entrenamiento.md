# Procedimientos de Administracion y Entrenamiento

## Procedimientos operativos
- Uso operativo del sistema para registro, revision y cierre de tramites.
- Administracion de usuarios, roles y permisos.
- Revision periodica de trazabilidad y logs.
- Respaldo y recuperacion segun politica TI.
- Gestion de incidentes y escalamiento tecnico.

## Entrenamiento minimo requerido
- Perfil solicitante: uso de solicitudes y consulta de historial.
- Perfil aprobador: revision, aprobacion/rechazo y trazabilidad.
- Perfil tecnico: administracion, monitoreo, cambios y evidencia.

## Responsables
- TICs: administracion tecnica y entrenamiento base.
- Responsable funcional: validacion de entendimiento operativo.
