# Retiro, Archivo y Retencion

## Archivo de evidencias
Las evidencias de validacion deben conservarse en repositorio documental controlado con trazabilidad por ID.

## Retencion documental
Mantener registros de validacion, desviaciones y aprobaciones segun politica institucional de retencion documental.

## Retiro futuro del sistema o version
Cualquier retiro de version o sistema debe incluir plan de preservacion de datos, evidencia historica y continuidad operativa.

## Preservacion de registros
Asegurar legibilidad, accesibilidad y trazabilidad de registros durante el periodo de retencion.

## Control de versiones retiradas
Documentar version retirada, fecha, motivo, aprobaciones y referencia de reemplazo.

## Criterio de archivo
El expediente pasa a estado archivado solo cuando cierre validacion, aprobaciones y evidencia objetiva esten completos.
