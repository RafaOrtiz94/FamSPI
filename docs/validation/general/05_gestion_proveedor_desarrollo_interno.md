# Gestion de Proveedor y Desarrollo Interno

## Modelo de desarrollo
FamSPI v1.0.0 se gestiona como desarrollo interno para el alcance funcional validado.

No aplica proveedor externo para el desarrollo funcional validado; el sistema se gestiona como desarrollo interno.

## Responsabilidades del equipo de TI
- Desarrollo y mantenimiento del sistema.
- Implementacion de controles tecnicos.
- Gestion de incidencias y cambios.
- Soporte a validacion documental y evidencia objetiva.

## Control de cambios del desarrollo
Todo cambio posterior debe registrar solicitud, impacto, aprobacion y validacion proporcional antes de incorporarse al estado validado.

## Revision del desarrollo
La revision se sustenta en evidencia de repositorio, version, commit y resultado de pruebas disponibles.
